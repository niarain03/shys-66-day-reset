# Shy's 66-Day Reset

A local-first, mobile-first 66-day habit reset game.

## Hosting
This is a static PWA: no build step and no backend required. Host the repository with GitHub Pages (root of `main`) or any static host.

## Persistence
Progress is stored in the browser's localStorage. Progress photos use IndexedDB. Use the app's JSON export/import to back up or move devices.
